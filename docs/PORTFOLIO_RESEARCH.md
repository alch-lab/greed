# 20%+ 组合研究（2026-07-30）

## 当前候选

- 主策略：`strategy-final.toml`，MR 每笔风险 3%。
- 趋势 sleeve：BTC 日线 EMA10/100 多空，固定 0.10x 名义敞口。
- MR 使用 Rust 逐笔精确回测；趋势信号使用 2020 年起数据预热，方向切换扣 7bps。

| 时期 | MR 3% | MR 3% + 趋势 0.10x | 组合日度最大回撤 |
|---|---:|---:|---:|
| 2025 | +19.62% | **+20.70%** | 9.00% |
| 2026 H1 | +22.38% | **+25.47%** | 5.33% |

## 判断

候选在两个验证期都越过 20%，但尚不能称为已验证生产策略：

1. 主要收益来自把 MR 风险从 1.5% 提高到 3%，不是新 alpha；趋势 sleeve 仅贡献约 1%（2025）。
2. MR 样本只有 17 + 14 笔，3% 风险下连续 3–4 次完整止损可能造成约 9%–12% 回撤。
3. 日线趋势长期有效，但 2026-07 当前持空，7 月约亏 3.9%，不能捕捉最近的多日摆动。
4. 首层限价采用“价格穿越即成交”，真实 maker 排队和漏单仍需模拟盘验证。

因此当前状态是“达到历史数值门槛的高风险候选”，不是可直接上线的 20% 承诺。

## 稳健性压力测试

候选没有通过“稳健 20%”门槛：

- 2025 成本变为基准的 1.5 倍时，组合收益从 20.70% 降至 16.65%；成本 2 倍时为 12.73%。
- maker 随机漏单 10% 的固定仓位近似中，2025 收益第 10 百分位只有 7.95%。
- 18 个月日收益做 30/60/90 日块自助法，三年 CAGR 第 10 百分位约 11.7%–12.7%，达到 20% 的概率约 67%–72%。
- 31 个 MR 回合按每年 21 笔重采样并固定加入 4% 趋势收益：年度收益中位数约 31%，但第 10 百分位约 -9%，亏损概率约 17%。这反映小样本和肥尾，不能把中位数当承诺收益。

可被当前证据支持的保守收益水平更接近 **12% 左右**，而不是稳定 20%。若仍以 20% 为目标，必须接受收益不达标概率约三成、显著漏单敏感性和约 15%–20% 的压力回撤，或取得更多真正样本外 MR 交易后再评估。

## 四层组合实验

统一组合：极端 MR + EMA10/100 日线趋势 0.10x + 现货多/永续空 funding carry，
以及每日一次 $10 永续执行探针。Carry 常驻，开平计现货往返 20bps、永续往返
8bps；探针按往返 10bps 计成本。

| 组合 | 2025 净收益 / DD | 2026H1 净收益 / DD |
|---|---:|---:|
| MR 1.5% + 趋势 + 探针 | +11.24% / 6.15% | +13.99% / 2.66% |
| 上述 + carry 0.25x | **+12.60% / 6.01%** | **+14.07% / 2.69%** |
| MR 3% + 趋势 + 探针 | +20.69% / 9.00% | +25.47% / 5.33% |
| 上述 + carry 0.25x | **+22.16% / 8.86%** | **+25.56% / 5.33%** |

Funding 原始数据：2025 名义累计 +5.13%（1095 次、87%为正）；2026H1 仅
+0.56%（543 次、62%为正）。用7日均值做开关会因双腿换仓成本在2026H1转负，
因此采用低换手常驻。0.25x carry 约占用 $25k 现货和 $8.3k 的3倍永续保证金；
尚未计现货/永续基差偏移、借贷利息、双腿不同步和清算尾险，这些只能由双腿模拟盘验证。

模拟盘可观测性：资金费每天约3次入账；$10探针每天1次往返，理论年成本约$3.65；
MR仍约21笔/年，趋势约4–6次切换/年。探针只验证下单、成交、止损、Journal和恢复，
不得纳入alpha统计。

推荐模拟盘使用低风险组合（MR 1.5% + 趋势0.10x + carry0.25x + $10探针）。
它的证据支持约12%级收益，不支持20%。MR 3%版本虽在原始双期超过20%，仍未通过
成本、maker漏单和重采样压力门槛，只能作为激进研究档，不能作为承诺收益。
