# Greed Demo 架构

## 安全边界

- 下单、成交、仓位、止损和止盈全部由 Binance Futures Demo/Testnet 返回。
- 配置校验拒绝 Binance 主网执行域名。
- API key 只从 `BINANCE_DEMO_API_KEY` 和 `BINANCE_DEMO_API_SECRET` 环境变量读取。
- 不存在本地撮合和虚构成交。

## 数据与币池

单条全市场 `!ticker@arr` WebSocket 负责发现。每15秒按24小时成交额和
1m/5m/15m价格异动重排，保留最多46个可执行 USDT 永续，与研究币池覆盖对齐。活跃币订阅：

- 15m、5m、1m K线；
- aggTrade 主动成交；
- 20档、500ms盘口。

运行时计算10秒/60秒快照OFI、价格响应、60秒主动买卖金额、spread、深度和预估滑点。
首次进入币池时才用REST补齐K线；不再拉取无资金策略需要的OI、Hyperliquid或清算数据。
币池换入换出通过常驻WebSocket上的增量`SUBSCRIBE/UNSUBSCRIBE`完成，不重建其他币种的
market/depth连接；重连成功后清除历史连接错误，盘口就绪统计只计算当前币池。
账户、仓位与保护单每5秒与Binance Demo对账；前端只读本地状态接口，不会因刷新频率增加交易所请求。

## SFP失败突破反转

1. 将完整15m K线聚合为1h结构，只使用已经收盘的数据；
2. 当前1h K线上刺过去288小时最高点0.10–1.25 ATR，随后收回前高下方；
3. 拒绝K线必须收阴、收盘位于区间下40%，成交额不低于过去36小时中位数；
4. 不在收回瞬间猜顶，等待之后最多三小时内跌破拒绝K线低点；
5. 确认后超过5分钟、已经走出0.5R、结构止损超过3%，或再次越过扫高极值都禁止追入；
6. 当前walk-forward只支持做空，多头SFP不获得资金；Demo单笔风险0.25%，结构止损，2R全平，
   最长持仓180分钟。

这条lane属于小样本Demo验证：训练12笔PF 1.053、验证6笔PF 1.242、锁定测试3笔PF
46.14。锁定PF由极少交易造成，不能理解为稳定收益。完整研究见
`research/sfp-liquidity-sweep-2026-08-25.md`。

## 趋势延续

1. 4h绝对涨跌至少6%，12h方向一致，路径效率至少45%；
2. 最近三个完整15m K线触及EMA21，最新K线重新站回EMA8并延续；
3. 1h量能不低于24h小时均值的65%，主动成交不逆向；
4. 盘口新鲜，spread不超过6bp，双侧20档较弱一侧深度至少20,000 USDT；这仍约为标准
   2,000 USDT趋势仓位的10倍；
5. 单笔风险0.6%，初始止损1.25%，2R平40%；到达+0.5R先保护交易成本，+1R后用
   0.5%距离跟踪剩余仓位；
6. 开仓三分钟后如果最高仍未达到+0.2R、当前却已经跌到-0.5R，判定延续失败并主动平仓，
   不再机械等待完整-1R止损。交易所远端初始止损始终保留，快速下跌时仍由其兜底。

通过条件后先在盘口被动侧挂GTX 60秒，每15秒最多重挂一次，主单相对信号参考价最多追8bp；
仍未成交时重新读取最优对手价，只有不利漂移不超过20bp才以原计划仓位的5%做市价探针。

风险/退出参数使用分钟级walk-forward选择：训练17笔PF 1.438，验证5笔PF 1.661；未参与选参的
锁定窗口12笔PF 1.060、净收益3.58 USDT、最大回撤1.94%、最差单笔-13.06 USDT。相同信号和
成本口径下，旧版锁定窗口净亏51.84 USDT、最大回撤4.76%、最差单笔-22.00 USDT。压力成本
（入场5bp、退出10bp）下仍亏5.29 USDT，因此该改动定位为降低尾部风险的Demo候选，不能视为
已经证明稳定盈利。

## 相对弱势空头

1. 只处理BTC之外的币种，完整15m K线的1h和4h收益分别至少落后BTC 0.5%和1%；
2. EMA8 < EMA21 < EMA36，并首次收盘跌破前四根15m K线低点；
3. 15m主动成交不平衡不高于-5%，最近1h成交额不低于过去24h小时均值的80%；
4. BTC自身4h跌幅低于-2%时停止该分支，瀑布行情交由趋势策略，避免重复解释；
5. 使用最近1h高点加0.1 ATR作为结构止损；风险0.15%，名义仓位最多1倍权益；
6. 0.75R全平，最多持仓30分钟。信号时效120秒，直接taker入场，回测按每边8bp成本计算。

训练和验证只用于选参；锁定窗口9笔、PF 1.261、盈利2.54 USDT，最近窗口16笔、PF 10.10、
盈利29.24 USDT。最近样本仍短，因此继续受独立滚动PF门控约束。

## 点火冲刺

1. 完整5m K线涨跌至少1%，10m同向延续，成交额至少为36根5m中位数的3倍；
2. 主动成交不平衡至少20%，收盘位于K线方向端并突破前30分钟微区间；
3. 30分钟累计延伸不超过3%，单根5m不超过3.5%，避免追入末端；
4. 点火后三分钟内出现至少0.15 ATR微回踩，但不得超过1 ATR；
5. 最新已收盘的1m K线重新同向且1m主动成交一致；10秒OFI和60秒主动流继续记录用于研究，但在没有
   历史逐笔数据验证前不作为实盘硬门；
6. 在盘口被动侧偏移0.05 ATR挂GTX post-only限价，最长2分钟不成交撤单，与walk-forward的两根1m触价假设一致；
7. 单笔风险0.25%，1 ATR止损，1.25R全平，最长持仓10分钟。

## 远端执行

- SFP在被动侧挂60秒，未成交即放弃，禁止追价；
- 趋势采用60秒自适应maker和5%有界taker探针；相对弱势突破按已计入回测的taker成本执行；
- 趋势maker等待期间共享主网WebSocket盘口和成交流：穿透计划入场位30bp、实时流与10秒价格同时
  反向，或守护行情持续失联5秒都会撤单；竞态成交会立即reduce-only平仓；
- 所有计划止盈使用Binance远端reduce-only GTC限价单；正常触价时计为maker，若下单前价格已穿过
  目标则允许立即成交，不因GTX拒单触发错误的紧急平仓；
- 初始止损、日损/回撤熔断和保护失败紧急平仓始终保留市价/条件市价taker路径；
- 成交历史同时记录maker/taker笔数和各自成交额，用于核对真实手续费节省。

## 组合风控

- 初始权益基准2,000 USDT；
- 最多3个持仓，同币不重复；
- 单笔名义仓位不超过1.5倍权益，总名义敞口不超过4倍权益；
- UTC单日亏损2.5%或峰值回撤10%时停止新开仓；
- 每个策略和方向分别统计最近20笔；至少8笔后PF低于1，冷却6小时。
- 同一币种同时出现SFP、相对弱势或趋势候选时，只为优先级最高的一条生成仓位计划。

## 日志

`alpha-events.jsonl`记录完整诊断：完整K线、当前5m/1m、20档盘口、aggTrade/OFI、候选条件、
仓位计划、下单拒绝和数据健康。`alpha-history.jsonl`保存账户权益、成交、保护更新、退出、费用、
PnL、MFE、MAE和持仓时间。状态接口把各策略当前步骤、下一缺失条件、持仓动作和风控状态提供
给前端。
