## 二、关键发现（按重要性排序）

### 🔴 发现1：砖 CSV 分析存在「聚合偏差」（Aggregation Bias）

**现象**：Python 砖 CSV 分析显示裸≥3连反转胜率 **76.2%**（SL=50, H=10），但同一策略在逐笔回测中胜率只有 **23.6%**。

**根因**：砖 CSV 把逐笔数据聚合成了固定尺寸的砖，**高频波动被平滑掉了**。
- 砖 CSV 中一个砖的 low=109,500，但形成该砖期间的逐笔成交可能触及 109,450
- Python 分析检查「后续砖的 low/high 是否触及止损」， misses 了砖内的高频波动
- 回测引擎在每个逐笔成交上检查止损，真实波动导致止损率远高于砖级别估计

**影响**：基于砖 CSV 的「出场结构扫描」「条件边际分层」等结论**不可直接用于策略设计**。所有参数扫描必须在逐笔回测引擎中验证。

**判定**：这是本阶段最重要的发现，它解释了为什么交接文档中「全年回测 43 笔 42 负」与砖 CSV 分析的预期不符。

### 🟡 发现2：裸≥3连反转信号在逐笔级别无效

| 参数 | 回合数 | 胜率 | 判定 |
|------|--------|------|------|
| SL=50, min_chain=3 | 4440 | 23.6% | NoEdge |
| SL=50, min_chain=5 | 2240 | 25.5% | NoEdge |
| SL=50, min_chain=8 | 617 | 28.8% | NoEdge |

全部远低于 60.5% 无效性基线。链长过滤（≥5, ≥8）有微弱提升，但仍不过线。

### 🟡 发现3：费用是致命病灶

SL=50 时，4440 笔交易产生 86,507$ 费用（每笔 19.5$），几乎耗尽全部 100,000$ 本金。

即使信号有微弱边际，高频交易（月均 4000+ 笔）+ 双边费用也会吃掉所有利润。

**推论**：如果力竭反转框架要复活，必须大幅降低交易频率（月频 <100 笔）。

交接文档已知：C2 否决率 97.2%，反转砖 body/range 普遍 >0.4，与 Renko 几何天然冲突。

本次分析未推翻此结论——这是结构问题，非参数问题。

## 四、下一步建议

### 选项1：放弃力竭反转框架，转向 PR-9（AggDelta + OI）

**前提**：需要解决币安 OI/资金费率数据采集与入湖。
- 币安 API 提供 `/futures/data/openInterestHist` 等端点
- 需要新增 data collector 模块，定期拉取 OI 和资金费率
- 与现有 aggTrades 数据对齐时间戳

**预期**：AggDelta + OI 分位数信号是独立的维度，不与 Renko 几何冲突。

### 选项2：换标的或换 timeframe

- 当前分析仅限于 BTC USDT 永续
- 可尝试 ETH、SOL 等其他币种
- 或尝试更高 timeframe（日线/4h）的反转信号

### 选项3：回退到「绞肉机过滤」+ 超低频

如果坚持力竭反转框架，唯一可能的出路是：
- 链长≥10（月频 <100 笔）
- SL≥300（降低逐笔噪声扫出）
- 只保留 C1（放量）作为过滤
- 但即使如此，全年胜率能否过 60.5% 仍是未知数

**此选项风险极高，不建议优先尝试。**
